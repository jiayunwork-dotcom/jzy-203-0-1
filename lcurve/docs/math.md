# 数学说明

本文档给出模型、代表件、拟合、预测与先验的完整推导与误差分析。
符号：第 x 件工时 `T(x) = T1·x^b`，`b = ln LR / ln 2 ≤ 0`，学习率 `LR = 2^b`。

---

## 1. 代表件（lot midpoint）

批次 `i` 只知区间 `[F_i, L_i]`（`n_i = L_i−F_i+1` 件）与批总工时 `H_i`。
代表件 `x̄_i` 定义为：按曲线计算的单件工时 × 批量 = 批总工时

```
T1·x̄_i^b · n_i = H_i  =  T1·Σ_{x=F_i}^{L_i} x^b
```

### 1.1 精确式（默认）

`T1` 两边约去，对 `x̄` 直接求解（**闭式，无需迭代求根**）：

```
x̄ = ( (1/n)·Σ_{x=F}^{L} x^b )^{1/b}
```

极限情形：

- `b → 0`（LR→100%）：`x̄ → exp((1/n)Σ ln x)`（几何平均）；
- `n = 1`：`x̄ = F`（恒等，与 b 无关）；
- `b = −1`（LR=50%）：`x̄` 为调和平均。

`x̄` 依赖尚未拟合的 `b`，因此外层对 `b` 做定点迭代（§2.2）。

### 1.2 近似式（可选，用于对照）

把离散求和换成区间 `[F−½, L+½]` 上的积分（中点法则）：

```
Σ_{x=F}^{L} x^b  ≈  ∫_{F-½}^{L+½} x^b dx
x̄ ≈ [ ((L+½)^{b+1} − (F−½)^{b+1}) / ((b+1)·n) ]^{1/b}
```

`b→0` 时用 `∫ln x dx = x ln x − x` 的极限形式；`b→−1` 时用 `∫x^{-1}dx = ln x`。

### 1.3 近似误差分析

Euler–Maclaurin 一阶修正给出求和与积分之差：

```
Σ x^b − ∫ ≈ (1/24)·[f′(L+½) − f′(F−½)]，  f′(x) = b·x^{b−1}
```

相对误差传播到 `x̄ = (S/n)^{1/b}` 时 `b` 恰好约去：

```
ε_x̄ ≈ ( hi^{b−1} − lo^{b−1} ) / ( 24 · ∫_{lo}^{hi} x^b dx )
     hi = L+½, lo = F−½
```

`approxRepUnitErrorBound()` 取该式绝对值 × 安全系数 2 作为声明上界。
性质：

- **批量相对位置越大误差越大**：误差受批内曲率（`n/x̄` 的量级）控制，
  同样的批量，越靠前（F 小）误差越大；
- **最靠前的小批最差**：第 1 件单件批 `[1,1]` 是全包络最差情形；
- 随批次后移迅速衰减（实测见下表）。

实测（LR=80%）：

| 批次 | 精确 x̄ | 近似 x̄ | 相对误差 |
|---|---|---|---|
| [1,1] | 1.0000 | 0.9411 | −5.89% |
| [1,10] | 4.1689 | 4.1146 | −1.30% |
| [1,100] | 32.3581 | 32.2743 | −0.26% |
| [11,20] | 15.1393 | 15.1353 | −0.03% |
| [101,120] | 110.3007 | 110.3002 | ≈0 |

网格验证（LR∈[60%,100%]、F≤50、n≤200，`test/unit/representative.test.ts`）：
观测最差 7.78%（LR=60%、`[1,1]`），均在声明上界内。

### 1.4 近似式对拟合参数的影响（声明上界）

**声明上界**（`APPROX_FIT_ERROR_BOUND`，适用包络：LR∈[70%,100%]、
批量≤100、批数≥4、批次从第 1 件起）：

- 学习率绝对误差 ≤ **1 个百分点**；
- 首件工时相对误差 ≤ **5%**。

网格实测（`test/unit/fitApprox.test.ts`，T1=100、1000 件）：

| LR | 批量 | 学习率误差 | T1 相对误差 |
|---|---|---|---|
| 0.70 | 1 | 0.016pp | −0.20% |
| 0.70 | 100 | 0.030pp | −0.38% |
| 0.80 | 1 | 0.010pp | −0.11% |
| 0.80 | 100 | 0.011pp | −0.13% |
| 0.90 | 100 | 0.003pp | −0.03% |

批次位置的影响（LR=80%、批量 20、10 批）：从第 1 件起 0.036pp/−0.30%；
从第 101 件起 0.0001pp/−0.001%——**靠前的批次主导近似误差**。
观测最大值约为声明上界的 1/30（LR）与 1/13（T1），余量充足。

## 2. 拟合

### 2.1 对数空间加权最小二乘

模型线性化：`ln(H_i/n_i) = ln T1 + b·ln x̄_i + ε_i`，记 `y_i = ln(H_i/n_i)`、
`z_i = ln x̄_i`、`a = ln T1`。目标函数：

```
min_{a,b}  Σ_i w_i·(y_i − a − b·z_i)²  +  λ·(b − b_prior)²
```

最后一项为改型先验伪观测（§4），无先验时 λ=0。

选择对数空间的理由：工时误差以乘性（百分比）为主，对数空间方差齐性；
闭式解 + 经典区间，无需非线性优化的数值二阶导。原始空间最小二乘会让
早期大批量批次主导目标，且误差结构不再对称。

**权重 `w_i = n_i`**：若单件工时相对误差独立同分布（方差 σ²），批次均值
`H_i/n_i` 的对数方差为 σ²/n_i，故 `w_i = n_i` 是极大似然意义下的正确加权，
等价于按件加权。无噪声时权重不影响解（任何一致权重都过真值），
因此该选择不影响划分无关、缩放等性质。

### 2.2 b 的定点迭代

`z_i = ln x̄_i` 依赖未知的 `b`（§1.1）。迭代：

1. 初值：有先验取 `b_prior`；否则用代数中点 `(F_i+L_i)/2` 做一次加权回归；
2. 给定 `b_k`，按精确式算各批 `x̄_i(b_k)`；
3. 解 2×2 正规方程得 `(a_{k+1}, b_{k+1})`；
4. `|Δb|+|Δa| < 1e-12` 收敛（实测 < 10 次；上限 200 次并报告 `converged`）。

无噪声数据在真值处是**精确不动点**（残差恒为 0），故精确代表件 +
迭代能按 1e-6 相对误差还原参数；近似式的不动点略有偏移，偏移量即
§1.4 的拟合误差。

### 2.3 方差与置信区间

```
SSE = Σ w_i r_i²，  r_i = y_i − a − b·z_i
σ̂² = SSE/(m−2)                    （m ≥ 3，sigmaSource=estimated）
σ̂  = assumedCv = 0.05             （m ≤ 2 自由度为 0，sigmaSource=assumed）
Cov(a,b) = σ̂²·(XᵀWX + P)^{-1}     （P = [[0,0],[0,λ]] 为先验精度）
```

- `ln T1` 的区间端点取 exp，`LR` 的区间端点取 2^b（单调变换）；
- 分位数：estimated 用 `t_{0.975}(m−2)`，assumed 用 `z_{0.975}=1.96`；
- 无噪声数据 σ̂≈0，区间退化为点——这是"完全吻合"的正确表达。

### 2.4 数据量要求

- 无先验：≥2 批（2 个参数）；1 批返回 `insufficient_data`；
- 有先验：≥1 批（先验提供斜率，数据定截距）；
- 置信区间：m≤2 时用假定 CV 的保守区间，响应中明示 `sigmaSource`。

## 3. 预测区间

计划批次 `j`（`n_j` 件，区间 `[F_j, L_j]` 从当前 `nextUnit` 连续编号）：

```
H_j = T1·S_j，  S_j = Σ x^b
ln H_j = ln T1 + ln S_j
∇_j = [∂lnH_j/∂lnT1, ∂lnH_j/∂b] = [1, S_j′/S_j]，  S_j′ = Σ x^b ln x
Var(ln H_j) = ∇_jᵀ·Cov·∇_j + σ̂²/n_j
```

最后一项是批次的不可约噪声（与拟合的加权噪声模型一致：批总量的对数
方差 = σ²/n）。区间 `H_j·exp(±1.96·√Var)`。

总工时 `H = Σ H_j`：对数空间梯度按各批工时占比合并
`∇ = Σ (H_j/H)·∇_j`；噪声项（各批独立）`Σ (H_j/H)²·σ̂²/n_j`。

## 4. 改型先验

### 4.1 形式

只约束学习率：伪观测 `b ~ b_prior`，权重 `λ = K·w̄`

- `b_prior = log2(母型有效学习率)`；
- `K` = 先验强度（**等效批数**，默认 4）：直观含义"母型经验相当于 K 批
  本部件数据"；`w̄` 为本部件各批平均权重（批量加权下即平均批量），
  使 λ 与数据权重同量纲；
- 首件工时不加先验：改型继承"学得快慢"，不继承"第一件干多久"。

### 4.2 衰减

后验精度 = 数据信息 + λ，先验份额

```
share = λ / (λ + I_data)，  I_data = Σw_i(z_i−z̄_w)²
```

随批数与批间跨度（`z` 的离散度）自然增长而**自动衰减**，无需显式衰减表。
响应中的 `prior.informationShare` 即该值。

默认 K=4 时的典型行为（母型 LR=80%，自身真值 LR=70%，批量 10）：

| 自身批数 | 先验份额 | 拟合学习率 |
|---|---|---|
| 1 | ≈1.00 | 0.800（完全由先验决定，T1 由该批定） |
| 2 | ≈0.86 | ≈0.785（明显向母型靠拢） |
| 30 | ≈0.09 | ≈0.709 |
| 100 | <0.05 | ≈0.702 |

**数据只有一两批时**：1 批 → 学习率完全由先验决定，首件工时取"曲线以
先验学习率穿过该批"的值；2 批 → 先验仍占主导，除非两批跨度很大。

### 4.3 取值与继承链

先验均值按顺序取：母型**有效学习率**（自身拟合值；母型无数据时沿链取
其先验——多级改型可传递）→ 声明关系时的显式 `priorLearningRate`
（∈(0,1]，用于母型尚无数据的早期）→ 无先验。

### 4.4 说明

- 有先验时，追加与自身曲线完全吻合的数据，参数仍会向数据侧微调
  （先验份额继续衰减）——这是设计行为，不是 bug；"追加吻合数据参数
  不变"对无先验拟合严格成立；
- 先验不随 σ̂ 缩放：K 以"批当量"计，行为对成本工程师可解释、可预期。

## 5. 性质及其成立原因

| 性质 | 原因 |
|---|---|
| 工时×k → LR 不变、T1×k | 对数空间截距平移 ln k，斜率不变 |
| 批次划分无关（无噪声） | 任何划分下真值都是精确不动点，残差恒 0 |
| LR=100% → 每件相同 | b=0，代表件退化为几何平均，回归斜率为 0 |
| 追加吻合数据参数不变（无先验） | 新点在现有曲线上，不动点不变 |
| 无噪声还原 1e-6 | 精确代表件 + 定点迭代在真值处残差恒 0 |

## 6. 事件溯源与一致性

- 区间派生：批次区间 = f（生产顺序， 各批件数， 跳号），更正件数 → 后续
  区间整体平移；跳号以间隙大小记录，平移时保持不变；
- 串行化：同一部件 `pg_advisory_xact_lock` → 校验 → 追加 → 更新投影，
  同一事务提交；最终状态 = 按受理顺序串行处理；
- 时点一致：`recorded_at` 在锁内取 `clock_timestamp()`，与 `seq` 同调
  单调，"截至 T"= 当时已应用事件的前缀；
- 幂等：`event_id` 全局唯一约束；并发重号时第二个事务在锁内看到已
  提交的同名事件，返回 `duplicate:true`；
- 恢复：读模型（projections/parts）可随时从事件流整体重建。
